# Weerlicht: testscène

Technische testscène voor de webversie van Weerlicht. Je stelt een personage samen, kiest een pincode en krijgt een zegelkaart van vier woorden. Daarna loop je door een testdorp en voer je een testgesprek met een keuze, een bladzijde in het dagboek en een verandering van uiterlijk. Een geschreven bladzijde kun je verzegelen. De scène bevat geen verhaal: gesprekken en uitleg tonen plaatshouders.

Je personage, je keuzes en wat je in het dagboek typt, blijven in je eigen browser. Er wordt niets verstuurd. Gebruik een verzonnen pincode.

Achter de knop "Meetscherm" rechtsonder zit de meting van snelheid en laadtijd, en de test van de versleuteling.

Open de test: https://sjoerdpeters1988.github.io/weerlicht-chromebooktest/
