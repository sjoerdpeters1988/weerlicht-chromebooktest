# Weerlicht: testscène

Technische testscène voor de webversie van Weerlicht. Je stelt een personage samen en loopt door een testdorp. De scène bevat geen verhaal: gesprekken tonen plaatshouders.

De naam en het uiterlijk van je personage blijven in je eigen browser. Er wordt niets verstuurd.

Achter de knop "Meetscherm" rechtsonder zit de meting van snelheid en laadtijd.

Open de test: https://sjoerdpeters1988.github.io/weerlicht-chromebooktest/
