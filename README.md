# Weerlicht: testscène

Technische testscène voor de webversie van Weerlicht. Je stelt een personage samen, loopt door een testdorp en voert een testgesprek met een keuze, een bladzijde in het dagboek en een verandering van uiterlijk. De scène bevat geen verhaal: gesprekken tonen plaatshouders.

Je personage, je keuzes en wat je in het dagboek typt, blijven in je eigen browser. Er wordt niets verstuurd.

Achter de knop "Meetscherm" rechtsonder zit de meting van snelheid en laadtijd.

Open de test: https://sjoerdpeters1988.github.io/weerlicht-chromebooktest/
